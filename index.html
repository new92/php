Run the collection

From the repository root, start the built-in PHP development server and open the URL below.

$ php -S 127.0.0.1:8080
↗ http://127.0.0.1:8080

Cleaner is CLI-only

Cleaner is intentionally not exposed in this web interface because it can delete files. Run its dry-run command explicitly from a terminal after reviewing the target.

$ php Cleaner/cleaner.php --help

Research and development use only

These are educational utilities, not production services. Use only authorized targets, configure host allowlists where required, and do not expose the local server publicly.
